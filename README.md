#### Описание проекта
Данный курсовой проект представляет собой модель шифровальной машины «Энигма» — электромеханического устройства, использовавшегося для шифрования и дешифрования секретных сообщений в первой половине XX века.

#### Цели проекта

* Изучение принципов работы шифровальной машины «Энигма».
* Разработка модели, имитирующей работу оригинальной машины.
* Исследование криптографической устойчивости шифра «Энигма».

#### Технологии

* Ядро программы backend написано на языке программирования C++.
* frontend реализован на языке программирования Python с использованием фреймворка PyQT

#### Запуск приложения
Существует три способа запуска приложения:

1. Чтобы запустить готовое приложение без настройки окужения, необходимо перейти в раздел Releases данного Github-репозитория (https://github.com/Misss-Lacoste/Enigma-Cipher-Machine/releases/tag/v1.0.0) и скачать архив с кодом под соотвктсвующую ОС: Windows или Linux. Необходимо распаковать архив и в открывшейся папке  `EnigmaApp` открыть файл `EnigmaApp.exe`.

2. Есть возможность склонировать данный репозиторий на свой ПК в случае, если установлен Python, Makefile.

    2.1. `git clone https://github.com/Misss-Lacoste/Enigma-Cipher-Machine`
   
    2.2.`cd /d/HSE/Enigma-Cipher-Machine`
    
    2.3. `pip install -r requirements.txt`

    2.4. `cd backend`

    2.5. `mingw32-make run`

    2.6. Далее в проводнике (в папке проекта) после успешной компиляции backend'а найти файл `EnigmaApp.bat` и открыть его.
  
4. Можно скомпилировать только backend-часть, не активируя при этом frontend и работать с консольной версией приложения. Для этого аналогично запускаем программу, используя команду `mingw32-make run` и наблюдаем интерактивный вывод в терминале.
